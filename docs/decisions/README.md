# 🧭 Architecture and Method Decision Records

Record decisions that materially change data handling, architecture, dependencies, validation, security, or project scope.

## Naming

Use `NNNN-short-title.md`, for example `0001-keep-dataset-provenance-explicit.md`.

## Required structure

1. Title and status: proposed, accepted, superseded, or rejected.
2. Date and decision owners.
3. Context and constraints.
4. Decision and rationale.
5. Alternatives considered.
6. Consequences, risks, and follow-up actions.

Use [the ADR template](../templates/adr-template.md). Keep decisions factual and link to relevant pull requests or experiment records.

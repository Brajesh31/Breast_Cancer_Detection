# 🧩 Examples

This directory is reserved for small, reproducible, non-clinical examples that explain data handling, visualization, validation, or safe experiment design.

## Contribution rules

- Use synthetic or clearly licensed public data.
- Keep examples small and runnable from a clean environment.
- State prerequisites and expected output.
- Include tests or a manual verification procedure.
- Avoid patient-level examples and diagnostic recommendations.
- Do not duplicate the primary notebook without a clear learning purpose.

## Current contents

No standalone example scripts are published here yet. The main educational artifact remains `Breast_Cancer.ipynb`.

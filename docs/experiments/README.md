# 🧪 Experiment Register

Use this directory for reviewed experiment records. Each experiment should be a separate Markdown file named with a date and short identifier, for example `2026-11-17-baseline-review.md`.

## Required sections

- Objective and hypothesis
- Dataset identity, provenance, and checksum
- Git commit and environment
- Target and feature definitions
- Split and validation design
- Preprocessing and model configuration
- Results with class-specific metrics and uncertainty
- Error analysis and limitations
- Reviewer and decision

Start from [the experiment plan template](../templates/experiment-plan-template.md). Do not record patient-identifiable data or confidential health information here.

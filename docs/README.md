## 🧱 Current implementation versus future work

| Area | Current state |
|---|---|
| Notebook exploration | Present |
| Local CSV | Present |
| Descriptive inspection and plots | Present |
| Correct diagnosis classifier | Not currently implemented |
| Valid model evaluation | Not established |
| API, web interface, database | Not present |
| Production deployment | Not present |
| Clinical validation | Not performed |

Documentation intentionally does not invent absent services, interfaces, deployment environments, or performance metrics.

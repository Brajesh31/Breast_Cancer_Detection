# Support

## Where to ask

- For reproducible repository issues or focused improvement proposals, open an issue in the [GitHub repository](https://github.com/Brajesh31/Breast_Cancer_Detection/issues).
- For setup and notebook questions, review [Installation](docs/installation.md) and [Troubleshooting](docs/troubleshooting.md).
- For suspected vulnerabilities or accidentally exposed restricted data, follow [SECURITY.md](SECURITY.md) and use a private reporting channel.
- For conduct concerns, see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) and contact the maintainer privately via [@brajesh31](https://github.com/brajesh31).

## Include in a useful report

State your operating system, Python and package versions, the notebook cell or command involved, the error message, and steps to reproduce the issue. Include a minimal excerpt where possible. Remove credentials, personal information, and patient data before sharing logs or screenshots.

## Project scope

This is an individual educational repository, not a supported medical product or hosted service. There is no clinical support, diagnostic advice, uptime guarantee, or guaranteed response time.
